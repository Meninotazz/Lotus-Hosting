# 🚀 Website - Hospedagem de Minecraft

Este é o código-fonte do site oficial da nossa hospedagem de Minecraft. O site foi desenvolvido do zero utilizando HTML5 e CSS3, focado em alta performance, carregamento rápido e design responsivo.

---

## 📌 Recursos do Site

- 📱 **Design Responsivo:** Adaptado para celulares, tablets e computadores.
- ⚡ **Carregamento Rápido:** Feito com código limpo sem dependências pesadas.
- 💰 **Tabela de Planos:** Exibição clara de recursos (RAM, CPU, Armazenamento) e preços.
- 🛒 **Integração Direta:** Botões direcionados para checkout e suporte via Discord.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura do site.
- **CSS3:** Estilização e layout responsivo (Flexbox).
- **GitHub Pages:** Hospedagem gratuita e implantação contínua.
